# UX Decision — Compact rule explanations

Date: 2026-09-04

Decision:
- Gate status and actionable values stay visible.
- Long rule text, methodology and evidence detail move behind tappable info icons.
- Explanations must remain available on demand and closable without navigation.
- This pattern should be reused for later Decision Gates where explanatory text would otherwise dominate the mobile Investment-Akte.
- Safety-critical state (PASS / FAIL / OPEN / LOCKED) must never be hidden behind the info control.

Reason:
Keep HPOS mobile-first, compact and self-explanatory without turning the Investment-Akte into a long policy document.
