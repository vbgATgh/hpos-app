# Alpha 4.3.2 Scope

Ziel: die beim mobilen Test gefundenen Halal- und News-Inkonsistenzen korrigieren, ohne die local-first Grundregeln zu schwächen.

- Halal: aktuelles Urteil je Quelle deterministisch; Historie unveränderlich; Konflikte sicher behandeln.
- News: Scope/Qualität/Suche vor Pagination; keine Rio-Dominanz durch kumulierte Direktadapter.
- Quellen: offizielle Primärquellen-Referenz für jede der 19 realen Depotpositionen.
- Performance: 20er-Pagination bleibt; Watchlist-Discovery bleibt rotierend.
- Kein automatisches Halal-H1 ohne belastbare Screening-Schnittstelle.
