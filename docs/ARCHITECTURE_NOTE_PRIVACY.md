# Privacy Boundary – P0

Das Repository ist aktuell öffentlich, während `data/portfolio/parqet_snapshot.json` reale Depotdaten enthält. Dieser Zustand ist für eine dauerhafte produktive Nutzung nicht akzeptabel.

Geplantes Ziel:
- öffentlich: App-Code, allgemeine Markt-/News-Snapshots, generische Asset-Stammdaten
- privat/lokal: Stückzahlen, Einstand, Cash, Transaktionen, Dividenden, Brokerzuordnung, persönliche Strategie, Halal-Historie und Notizen
- Migration erst nach geprüftem Backup/Restore und ohne Verlust der local-first Daten

Bis zur Umsetzung gilt der aktuelle reale Snapshot als Übergangslösung der Alpha-Phase.
